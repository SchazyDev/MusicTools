# Ресурсы

Каталог попадает в установленное приложение целиком (`resources/*` в
`tauri.conf.json`). Сюда кладутся внешние программы, которые приложение
ищет до всех остальных мест.

## Сайдкары

| Файл | Назначение |
| --- | --- |
| `yt-dlp.exe` | Скачивание видео и аудио по ссылке |
| `ffmpeg.exe` | Извлечение звука и конвертация форматов |

Порядок поиска программы:

1. каталог ресурсов (этот каталог);
2. каталог, где лежит `music-tools.exe`;
3. каталоги из переменной `PATH`;
4. только в отладочной сборке: `python -m yt_dlp` и `ffmpeg.exe` в корне
   репозитория.

В релизе шаги 1–3 обязательны: без файлов в этом каталоге инструменты
скачивания и конвертации сообщат об ошибке с подсказкой, где искать программу.

## Почему файлы не хранятся в git

`ffmpeg.exe` весит около 140 МБ, поэтому в репозитории он лежит в корне и
отслеживается Git LFS. Копировать его сюда вручную нужно только при сборке
установщика.
