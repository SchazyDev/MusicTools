# QA: ручная приёмка релиза v1.1.0

Проверка выполняется вручную на чистой копии Windows 10 или Windows 11.
Перед началом рекомендуется установить предыдущую версию (1.0.0), если пункт
проверки этого требует, и сохранить журнал `fauna_tools.log`.

Журнал по умолчанию: `%LOCALAPPDATA%\MusicTools\fauna_tools.log` (если файл там
отсутствует — искать рядом с исполняемым файлом или в каталоге запуска).

## 1. Чистая установка без прав администратора

1. Войти в систему под учётной записью без прав администратора.
2. Запустить установщик `MusicTools-Setup-1.1.0.exe`.
3. Пройти установку, не подтверждая запросы.

Ожидаемый результат: запрос UAC не появляется. Приложение установлено в
`%LOCALAPPDATA%\Programs\MusicTools`. Ярлык «Music Tools» создан на рабочем
столе и в меню «Пуск».

## 2. Установка с повышением прав в Program Files

1. Запустить установщик через «Запуск от имени администратора».
2. Подтвердить запрос UAC и выбрать каталог внутри `Program Files`.
3. Завершить установку и запустить приложение из меню «Пуск».

Ожидаемый результат: приложение установлено в выбранный каталог внутри
`Program Files`, ярлыки созданы, приложение запускается и отображает иконку в
трее.

## 3. Проверка уровня целостности процесса

1. Запустить приложение ярлыком (не через «Запуск от имени администратора»).
2. Открыть «Диспетчер задач», вкладка «Подробности», добавить столбец «Уровень
   целостности» (или открыть Process Explorer и посмотреть свойства процесса).

Ожидаемый результат: уровень целостности — «Средний» (Medium), процесс НЕ
запущен с повышенными правами. Перетаскивание из Проводника и автозапуск
работают.

## 4. Перетаскивание файлов в список конвертации

1. Открыть вкладку конвертации.
2. Выделить в Проворнике несколько файлов поддерживаемых форматов.
3. Перетащить их в список конвертации.

Ожидаемый результат: курсор при перетаскивании показывает «копировать»
(плюсик), все файлы добавляются в список, счётчик файлов увеличивается на их
количество.

## 5. Перетаскивание папки

1. Подготовить папку, содержащую несколько аудио- и видеофайлов, включая файлы
   во вложенных подпапках.
2. Перетащить папку в список конвертации.

Ожидаемый результат: добавляются все поддерживаемые файлы из папки и её
подпапок (рекурсивно). Файлы неподдерживаемых форматов пропускаются.

## 6. Перетаскивание файла неподдерживаемого формата

1. Перетащить в список конвертации файл с расширением вне списка
   поддерживаемых (например, `.txt` или `.pdf`).

Ожидаемый результат: появляется предупреждение о неподдерживаемом формате.
Список файлов не меняется, счётчик остаётся прежним.

## 7. Скачивание mp4 с выбором разрешения

1. Открыть вкладку скачивания, вставить ссылку на видео.
2. Выбрать формат mp4 и разрешение (например, 720p).
3. Запустить скачивание.

Ожидаемый результат: до начала скачивания отображаются превью и заголовок
видео. Файл скачивается в выбранном разрешении в указанную папку, прогресс
увеличивается до 100%, по завершении появляется уведомление.

## 8. Скачивание mp3 и wav

1. Скачать тот же ролик в mp3.
2. Скачать тот же ролик в wav.

Ожидаемый результат: для каждого файла прогресс последовательно проходит фазу
загрузки и фазу извлечения аудио. Файлы сохранены в указанной папке и
воспроизводятся во встроенном или системном плеере.

## 9. Отмена на каждой фазе

1. Запустить скачивание в mp3 и отменить во время фазы загрузки.
2. Повторить запуск и отменить во время фазы извлечения аудио.
3. Запустить конвертацию и отменить во время фазы конвертации.
4. Запустить конвертацию/скачивание и отменить во время фазы копирования
   результата.

Ожидаемый результат: операция отменяется без зависания интерфейса. До и после
каждой отмены каталог `%TEMP%` не содержит каталогов `audio_convert_*`,
`audio_extract_*` и иных временных каталогов приложения.

## 10. Пакетная конвертация в mp3, wav, flac, ogg

1. Добавить несколько файлов в список конвертации.
2. По очереди выполнить конвертацию в mp3, wav, flac и ogg.

Ожидаемый результат: для каждого формата все файлы конвертируются успешно.
Прогресс движется как от файла к файлу, так и внутри текущего файла (не
замирает на границах файлов). Итоговые файлы имеют правильный формат и
воспроизводятся.

## 11. Конфликт имён при сохранении

1. Сохранить в папку результат, где уже существует файл с тем же именем
   (например, конвертировать `song.mp3` в `song.wav` при наличии
   `song.wav`).

Ожидаемый результат: создаётся новый файл `song (1).wav`, существующий
`song.wav` не изменяется и не удаляется.

## 12. Автозапуск из трея

1. Открыть меню трея и включить автозапуск.
2. Открыть «Диспетчер задач» → «Автозагрузка» и реестр
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
3. Выключить автозапуск в меню трея.

Ожидаемый результат: после включения в реестре появляется ровно одна запись,
совпадающая по имени значения с установщиком; в «Автозагрузке» она
отображается как включённая. После выключения запись удаляется. Дублирующихся
записей не возникает.

## 13. Проверка обновлений при отсутствии манифеста

1. Установить версию 1.0.0. В релизе на GitHub намеренно отсутствует файл
   `latest.json`.
2. Запустить приложение.

Ожидаемый результат: обновление не предлагается, приложение запускается
нормально и полностью работоспособно. В `fauna_tools.log` появляется
предупреждение о невозможности проверить обновления (отсутствует манифест).
Запуск не блокируется.

## 14. Обновление с предыдущей версии при наличии манифеста

1. Установить версию 1.0.0. В релизе на GitHub есть корректный `latest.json`.
2. Запустить приложение и подтвердить предложение обновления.

Ожидаемый результат: обновление скачивается, проверка контрольной суммы
проходит, приложение перезапускается уже версией 1.1.0 (версия видна в окне
«О программе»).

## 15. Подмена контрольной суммы

1. В манифесте `latest.json` указать неверную контрольную сумму пакета
   обновления.
2. Запустить проверку обновления и подтвердить скачивание.

Ожидаемый результат: установка отклоняется, пользователю выводится сообщение
об ошибке проверки контрольной суммы. Установленная версия не меняется.

## 16. Запуск из исходников

1. Запустить приложение командой `python main.py` из каталога проекта.

Ожидаемый результат: приложение запускается, фоновая проверка обновлений не
выполняет установку и не перезапускает процесс. Обновление не выполняется.

## 17. Отсутствующий или нерабочий ffmpeg

1. Переименовать/удалить `ffmpeg.exe` из каталога приложения (или установить
   нерабочий файл на его место).
2. Запустить приложение.

Ожидаемый результат: после запуска появляется окно «FFmpeg not found» с
пояснением. После закрытия окна приложение полностью завершается: иконка в
трее не появляется, процесс в «Диспетчере задач» исчезает. В `fauna_tools.log`
есть запись об ошибке.

## 18. Журнал ошибок

1. Выполнить действия из пунктов 6, 15 и 17.
2. Открыть `fauna_tools.log`.

Ожидаемый результат: файл журнала создаётся при запуске и содержит записи об
ошибках и предупреждениях, соответствующие выполненным сценариям (с отметкой
времени).

## Что приложить к отчёту об ошибке

- Версия приложения (окно «О программе») и версия Windows (например, Windows 11
  23H2, сборка 22631.x).
- Разрядность системы (x64) и способ установки (без прав администратора /
  в `Program Files` / запуск из исходников).
- Точная последовательность шагов воспроизведения: что перетаскивали или
  скачивали, какие форматы и разрешения выбирали.
- Файл `fauna_tools.log` целиком.
- При необходимости — снимки экрана или видео на момент ошибки.
