**Music Tools** – настольная программа для Windows, которая скачивает видео и музыку по ссылке и конвертирует уже имеющиеся на компьютере медиафайлы в популярные форматы. Всё происходит на вашем компьютере: программа ничего не требует настраивать, не просит регистрации и не нуждается в правах администратора.

## Возможности

- **Скачивание по ссылке** – вставьте адрес страницы с видео или музыкой, программа сама найдёт доступные варианты.
- **Предпросмотр перед скачиванием** – обложка, название и список доступных разрешений появляются автоматически.
- **Выбор формата и качества** – для видео это MP4, для звука – MP3 и WAV, качество подстраивается под выбранный формат.
- **Конвертация локальных файлов** – MP4, AVI, MKV, MOV, FLV, WMV, WEBM, MP3, WAV, FLAC, AAC, OGG, M4A на входе; MP3, WAV, FLAC, OGG на выходе.
- **Перетаскивание файлов и папок** – можно перетащить файлы прямо из Проводника, а можно добавить их через диалог выбора.
- **Сохранение без затирания** – если файл с таким именем уже есть, к имени добавляется номер, и старый файл остаётся на месте.
- **Понятные ошибки** – при сбое программа показывает настоящую причину, а не общее сообщение.
- **Работа в трее** – окно можно свернуть в область уведомлений и открыть из неё в любой момент.
- **Автообновление** – при выходе новой версии программа предложит её установить.

## Системные требования

| Параметр | Значение |
|----------|----------|
| Операционная система | Windows 10 или Windows 11, 64-битная |
| Свободное место на диске | около 250 МБ (в состав уже входит FFmpeg) |
| Права администратора | не требуются |
| Интернет | нужен для скачивания медиа и для проверки обновлений |
| Учётная запись | не нужна, регистрация отсутствует |

## Установка

### Установка без прав администратора

Это обычный способ установки. Запустите скачанный установщик и следуйте подсказкам. Windows не покажет запрос на повышение прав, а программа разместится в вашей личной папке:

```
%LOCALAPPDATA%\Programs\MusicTools
```

Всё, что нужно для работы, уже упаковано внутри: отдельно ставить FFmpeg или что-либо ещё не требуется.

### Установка для всех пользователей

Если вы хотите установить программу для всех пользователей компьютера, запустите установщик от имени администратора (правый клик по файлу, затем «Запуск от имени администратора») и подтвердите запрос системы. В этом случае программа будет установлена в общую папку `Program Files`. В остальном установка такая же, как и обычная.

### Выбор канала обновлений

Программа обновляется сама. Канал по умолчанию — `stable`: подписанные манифесты с проверкой подписи и контрольной суммы. Канал `beta` включает предварительные сборки и переключается в настройках.

### Первый запуск

- Некоторые антивирусы и защитник Windows могут показать предупреждение о неизвестной программе. Это типичная реакция на новую программу без цифровой подписи. Если вы скачали её с официальной страницы релизов, выберите вариант «Подробнее» и затем «Выполнить в любом случае».
- При закрытии окна программа не завершается, а сворачивается в область уведомлений (трей) рядом с часами. Чтобы закрыть её совсем, воспользуйтесь пунктом «Выход» в меню значка в трее.
- Журнал работы ведётся в `%APPDATA%\MusicTools\music_tools.log`. Он пригодится, если понадобится сообщить о проблеме; путь можно открыть на вкладке «О программе».
- Во вкладке «О программе» показано, какая версия yt-dlp используется. Если сайты перестали открываться, нажмите «Обновить yt-dlp» — обновление ставится в профиль пользователя и не требует прав администратора.

## Как скачать видео или музыку

1. Откройте вкладку **Download**.
2. Вставьте в поле адрес страницы с видео или музыкой. Через короткую паузу программа сама подгрузит предпросмотр: обложку, название и список доступных разрешений для этого видео.
3. Выберите формат в списке **Format**: `mp4` для видео либо `mp3` или `wav` для звука.
4. Выберите качество в соседнем списке. Он подстраивается под формат:
   - для `mp4` – разрешения, которые реально доступны у этого видео (например, 1080p, 720p, 480p, 360p);
   - для `mp3` – битрейт от 320 до 32 кбит/с;
   - для `wav` – 16bit, 24bit или 32bit.
5. Нажмите **Download**. Во время работы кнопка сменится на **Cancel**, а внизу будет расти полоса прогресса. При необходимости нажмите **Cancel**, чтобы остановить скачивание.
6. Когда файл будет готов, откроется диалог «Сохранить файл как» – выберите папку и имя. Копирование файла в выбранное место тоже показывается отдельной полосой прогресса.
7. Если файл с таким именем в выбранной папке уже есть, программа ничего не перезаписывает: к имени добавится номер, например `Track (1).mp3`.

## Как конвертировать файлы

1. Откройте вкладку **Convert**.
2. Добавьте файлы любым удобным способом:
   - перетащите их из Проводника прямо в список;
   - щёлкните по пустому месту списка или по строке **Add Files...**, чтобы открыть диалог выбора файлов.
3. Можно перетащить сразу целую папку – программа добавит все подходящие медиафайлы из неё, включая файлы во вложенных папках. Файлы, которые уже есть в списке, повторно не добавляются, а неподдерживаемые форматы отклоняются с предупреждением.
4. Поддерживаются входные форматы: `mp4`, `avi`, `mkv`, `mov`, `flv`, `wmv`, `webm`, `mp3`, `wav`, `flac`, `aac`, `ogg`, `m4a`.
5. Уберите ненужные строки кнопкой с крестиком справа от файла либо очистите весь список кнопкой **Clear**.
6. Выберите формат в списке **Format**: `mp3`, `wav`, `flac` или `ogg`.
7. Выберите качество – список зависит от формата:
   - `mp3` – битрейт от 320 до 32 кбит/с;
   - `wav` – 32bit, 24bit или 16bit;
   - `flac` – разрядность (24bit или 16bit) вместе со степенью сжатия от 0 до 12;
   - `ogg` – битрейт от 450 до 48 кбит/с.
8. Нажмите **Convert**. Кнопка сменится на **Cancel**, а полосы прогресса покажут и обработку текущего файла, и общий ход по всему списку. Кнопкой **Cancel** можно остановить работу.
9. По окончании программа попросит выбрать папку для готовых файлов, после чего скопирует их туда с показом прогресса; копирование тоже можно отменить.
10. Если что-то пойдёт не так, программа покажет настоящую причину ошибки от FFmpeg, а не общее «не удалось».

## Таблица параметров качества

| Формат | Доступные параметры | Что это значит |
|--------|---------------------|----------------|
| MP3 | битрейт 320–32 кбит/с | Чем выше битрейт, тем лучше качество звука и тем больше размер файла. |
| WAV | 32bit, 24bit, 16bit | Разрядность звука: чем выше, тем точнее передаётся сигнал. Файлы WAV не сжимаются и занимают много места. |
| FLAC | разрядность 24bit/16bit и степень сжатия 0–12 | Сжатие без потери качества. Меньшая степень – быстрее, большая – компактнее. |
| OGG | битрейт 450–48 кбит/с | Чем выше битрейт, тем лучше качество при небольшом размере файла. |

Рекомендации:

- Для обычного прослушивания музыки выбирайте **MP3** с битрейтом 320 кбит/с: это удачное сочетание качества и размера.
- Для максимально точного архива музыкальных записей берите **FLAC** 16bit или 24bit.
- **WAV** имеет смысл для последующей обработки звука в других программах, а не для хранения.
- **OGG** подойдёт, когда нужен небольшой файл при достойном качестве.

## Работа из трея

Программа умеет работать из области уведомлений рядом с часами. Левый щелчок по значку показывает или скрывает окно. Меню значка (правый щелчок) содержит три пункта: **Open** – открыть окно, **Run on startup** – включать программу вместе с Windows, **Quit** – полностью закрыть программу. При закрытии окна программа по умолчанию сворачивается в трей, а не завершает работу.

## Обновление программы

После запуска программа в фоне обращается к странице релизов на GitHub и проверяет, нет ли более новой версии. Эта проверка не задерживает запуск: окно открывается как обычно, а проверка идёт параллельно. Если новая версия найдена, программа спросит ваше согласие, затем скачает обновление, проверит его контрольную сумму SHA-256 и установит. Если в релизе нет специального файла с описанием обновления, обновление не предлагается. Если программа запущена не из собранной версии, а напрямую из исходников, проверка обновлений отключена.

Если по какой-то причине автообновление не сработало, обновиться можно вручную: скачайте на странице релизов свежий установщик и установите его поверх старой версии. Все ваши настройки, включая автозапуск, сохранятся.

## Устранение неполадок

| Симптом | Возможная причина | Что сделать |
|---------|-------------------|-------------|
| Программа не запускается | Файл повреждён либо не установлены нужные системные компоненты (WebView2) | Переустановите программу тем же установщиком. На Windows 10 установщик сам доставит WebView2; если запуск всё равно не удаётся, приложите журнал из `%APPDATA%\MusicTools` к обращению. |
| При первом запуске Windows SmartScreen или антивирус выдаёт предупреждение | Программа новая и без цифровой подписи | Скачайте её с официальной страницы релизов. В окне SmartScreen выберите «Подробнее» и «Выполнить в любом случае»; в антивирусе добавьте файл в исключения. |
| Перетаскивание файлов ничего не делает | Файлы перетаскиваются не на вкладку «Конвертация» или перетаскивает не Проводник | Откройте вкладку «Конвертация» и перетаскивайте файлы в её список. Если перетаскивание из Проводника невозможно, добавьте файлы через диалог по клику по списку. |
| Скачивание не идёт или останавливается | Нет доступа к сайту, ссылка устарела или сайт изменил защиту | Проверьте интернет и откройте ссылку в браузере. Обновите программу до последней версии. Если сайт закрыт для скачивания, ссылку загрузить не получится. |
| Сообщение «не найдена программа ffmpeg» | Установка повреждена или файлы удалены антивирусом | Переустановите программу. На вкладке «О программе» видно, какие программы найдены и откуда. |
| После конвертации нет звука | Некоторые форматы не поддерживают многоканальный звук из исходника | Попробуйте другой формат на выходе (например, MP3 вместо OGG) или другой исходный файл. |
| Конвертация завершается ошибкой с непонятным текстом | Сам исходный файл повреждён или содержит дорожку, которую FFmpeg не может обработать | Прочитайте показанную причину – это реальное сообщение FFmpeg. Проверьте, открывается ли файл проигрывателем, и повторите конвертацию в другой формат. |
| Файл сохранился под другим именем | В папке уже был файл с таким же именем | Это сделано специально, чтобы не затереть старый файл: к имени добавлен номер, например `Track (1).mp3`. Переименуйте его или сохраните в другую папку, если нужно другое имя. |
| Обновление не предлагается | Установлена последняя версия, в релизе нет описания обновления либо программа запущена из исходников | Проверьте версию на вкладке «О программе» и сравните со страницей релизов. Скачайте новый установщик вручную. |
| Значок не появился в трее | Значок скрыт настройками Windows | Нажмите стрелку рядом с часами и откройте список скрытых значков; перетащите значок Music Tools на панель, чтобы он был виден всегда. |
| Для сообщения о проблеме нужен журнал | Понадобятся записи о работе программы | Журнал `music_tools.log` лежит в `%APPDATA%\MusicTools`; кнопка «Открыть журнал» на вкладке «О программе» откроет его в Проводнике. |

## Частые вопросы

**Куда сохраняются готовые файлы?**
При скачивании вы сами выбираете папку и имя в диалоге «Сохранить файл как», а при конвертации – папку для готовых файлов. Программа ничего не сохраняет без вашего выбора.

**Работает ли программа без интернета?**
Конвертация локальных файлов работает без интернета, потому что FFmpeg уже входит в состав. Для скачивания по ссылке интернет нужен.

**Отправляются ли мои данные куда-либо?**
Программа не требует регистрации и не собирает сведения о вас. Единственное фоновое обращение – проверка новых версий на GitHub; файлы и ссылки она при этом никуда не передаёт. Само скачивание идёт с того сайта, ссылку на который вы вставили.

**Сколько файлов можно конвертировать за раз?**
В список можно добавить сколько угодно файлов, включая содержимое целой папки. Они обрабатываются по очереди, а общий прогресс виден на полосе прогресса.

**Какие сайты поддерживаются?**
Программа надёжно работает с популярными видео- и аудиоресурсами, включая YouTube и VK Видео. Точный список сайтов зависит от самой программы скачивания и постоянно меняется, поэтому некоторые ссылки могут не поддерживаться.

**Почему в списке нет нужного разрешения?**
Программа показывает только те разрешения, которые реально доступны у этого видео. Если записи выложены, например, только в 720p, то выше качество выбрать нельзя – можно сохранить до максимального доступного для этого видео.

**Перезаписывает ли программа мои файлы?**
Нет. Если файл с таким именем уже есть, номер добавляется к новому имени, а старый файл остаётся нетронутым.

**Как удалить программу полностью?**
Удалите её через «Установка и удаление программ» либо запустите деинсталлятор из папки установки. Потом проверьте: отключите программу из списка автозагрузки в параметрах Windows (меню «Автозагрузка»), по желанию удалите ярлыки с рабочего стола и из меню «Пуск», и удалите папку `%APPDATA%\MusicTools` (настройки и журнал) и `%LOCALAPPDATA%\MusicTools` (обновлённая копия yt-dlp).
